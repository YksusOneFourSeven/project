# Введение

Лабораторная работа посвящена разработке информационной системы «Учет успеваемости студентов». Система объединяет справочники, планирование учебного процесса, ввод оценок и получение отчетов в одном веб-приложении. Главный результат работы — действующий учебный стенд с PostgreSQL, разграничением доступа и документированными проверками.

Основание разработки — задание «Лабораторная работа 1» [1]. В отчете последовательно представлены техническое задание, модель данных, варианты использования, план и протокол тестирования, руководство пользователя и материалы защиты. Описание физической базы и реализации включено в раздел модели данных, чтобы сохранить установленный порядок отчетности.

Используется веб-вариант из задания: HTML, CSS, JavaScript и Python. Основной серверный фреймворк — FastAPI; зависимости предоставляет Dishka. Для хранения выбрана PostgreSQL. Приложение разворачивается Docker Compose. Посещаемость в задании является необязательной и не входит в реализацию. Все демонстрационные сведения о людях вымышлены.
